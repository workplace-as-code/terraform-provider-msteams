# msteams_guest_messaging_configuration (Resource)

Manages the messaging features available to guest users (`CsTeamsGuestMessagingConfiguration`). This is a singleton: there is exactly one configuration per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Teams.

## Example Usage

```terraform
# Guests can chat but not delete chats, and see only strict Giphy content.
resource "msteams_guest_messaging_configuration" "this" {
  allow_user_chat        = true
  allow_user_delete_chat = false
  allow_giphy            = true
  giphy_rating_type      = "Strict"
  allow_memes            = false
}
```

## Schema

### Optional

- `allow_giphy` (Boolean) Allow guests to post Giphy images.
- `allow_immersive_reader` (Boolean) Allow guests to open messages in Immersive Reader.
- `allow_memes` (Boolean) Allow guests to post memes.
- `allow_stickers` (Boolean) Allow guests to post stickers.
- `allow_user_chat` (Boolean) Allow guests to chat.
- `allow_user_delete_chat` (Boolean) Allow guests to delete chats for themselves.
- `allow_user_delete_message` (Boolean) Allow guests to delete their messages.
- `allow_user_edit_message` (Boolean) Allow guests to edit their messages.
- `giphy_rating_type` (String) Giphy content rating for guests. Valid values: `Strict`, `Moderate`, `NoRestriction` (case-insensitive).

### Read-Only

- `id` (String) Always `Global`.

## Import

The resource is a singleton. Import it with the ID `Global`:

```terraform
import {
  to = msteams_guest_messaging_configuration.this
  id = "Global"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_guest_messaging_configuration.this
  identity = { id = "Global" }
}
```

Or with the CLI:

```shell
terraform import msteams_guest_messaging_configuration.this "Global"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
