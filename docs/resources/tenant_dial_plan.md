# msteams_tenant_dial_plan (Resource)

Manages a tenant dial plan, whose normalization rules translate the numbers users dial, such as extensions and short numbers, into E.164 numbers (`CsTenantDialPlan`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# Paris office: 4-digit extensions and 0 for the switchboard.
resource "msteams_tenant_dial_plan" "paris" {
  name        = "Paris"
  description = "Paris office"

  normalization_rules = [
    {
      name                  = "Extensions"
      pattern               = "^(\\d{4})$"
      translation           = "+3314567$1"
      is_internal_extension = true
    },
    {
      name        = "Switchboard"
      pattern     = "^0$"
      translation = "+33145670000"
    },
  ]
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `description` (String) Description of the dial plan.
- `normalization_rules` (Attributes List) Normalization rules, in the order Teams tries them: the first rule whose pattern matches the dialed number translates it. (see [below for nested schema](#nestedatt--normalization_rules))
- `simple_name` (String) Name of the dial plan shown in the clients. Defaults to the name.

### Read-Only

- `id` (String) The policy name (same as `name`).

<a id="nestedatt--normalization_rules"></a>
### Nested Schema for `normalization_rules`

Required:

- `name` (String) Name of the rule, unique in the dial plan.
- `pattern` (String) Regular expression the dialed number must match, for example `^(\d{4})$`.
- `translation` (String) Number to call, with `$1`, `$2`... for the groups of the pattern, for example `+3314567$1`.

Optional:

- `description` (String) Description of the rule.
- `is_internal_extension` (Boolean) Whether the rule translates an internal extension.

## Import

Import using the dial plan name. The `Tag:` prefix shown by `Get-CsTenantDialPlan` is accepted, and `Global` imports the org-wide dial plan:

```terraform
import {
  to = msteams_tenant_dial_plan.paris
  id = "Paris"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_tenant_dial_plan.paris
  identity = { id = "Paris" }
}
```

Or with the CLI:

```shell
terraform import msteams_tenant_dial_plan.paris "Paris"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
