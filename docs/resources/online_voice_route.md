# msteams_online_voice_route (Resource)

Manages a Direct Routing voice route: the called numbers it matches, the PSTN usages it belongs to and the session border controllers (SBC) that carry the calls (`CsOnlineVoiceRoute`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
resource "msteams_online_pstn_usage" "france" {
  name = "France"
}

# French numbers through the two SBCs of the Paris data centers.
resource "msteams_online_voice_route" "france" {
  name                 = "France"
  number_pattern       = "^\\+33\\d{9}$"
  priority             = 0
  online_pstn_usages   = [msteams_online_pstn_usage.france.name]
  online_pstn_gateways = ["sbc1.contoso.com", "sbc2.contoso.com"]
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `description` (String) Description of the route.
- `number_pattern` (String) Regular expression of the called numbers, for example `^\+33\d{9}$`.
- `online_pstn_gateways` (List of String) FQDNs of the session border controllers (SBC) of the route, as registered with `New-CsOnlinePSTNGateway`.
- `online_pstn_usages` (List of String) PSTN usages the route belongs to.
- `priority` (Number) Order of the routes of a PSTN usage that match a number: 0 first.

### Read-Only

- `id` (String) The policy name (same as `name`).
