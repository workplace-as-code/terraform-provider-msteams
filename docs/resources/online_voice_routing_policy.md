# msteams_online_voice_routing_policy (Resource)

Manages a Direct Routing voice routing policy: the PSTN usages, in order, whose voice routes the calls of its users can take (`CsOnlineVoiceRoutingPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
resource "msteams_online_pstn_usage" "france" {
  name = "France"
}

resource "msteams_online_pstn_usage" "international" {
  name = "International"
}

# Users of this policy call French numbers first through the France routes.
resource "msteams_online_voice_routing_policy" "france" {
  name = "France"
  online_pstn_usages = [
    msteams_online_pstn_usage.france.name,
    msteams_online_pstn_usage.international.name,
  ]
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `description` (String) Description of the policy.
- `online_pstn_usages` (List of String) PSTN usages, in the order Teams tries their voice routes.

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix shown by `Get-CsOnlineVoiceRoutingPolicy` is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_online_voice_routing_policy.france
  id = "France"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_online_voice_routing_policy.france
  identity = { id = "France" }
}
```

Or with the CLI:

```shell
terraform import msteams_online_voice_routing_policy.france "France"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
