# msteams_events_policy (Resource)

Manages a Teams events policy, which controls who can organize webinars and town halls (`CsTeamsEventsPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# Only internal attendees for webinars, no town halls.
resource "msteams_events_policy" "internal" {
  name              = "Internal-Events"
  description       = "Webinars for employees only"
  allow_webinars    = "Enabled"
  event_access_type = "EveryoneInCompanyExcludingGuests"
  allow_townhalls   = "Disabled"
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `allow_email_editing` (String) Organizers can edit event emails. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `allow_townhalls` (String) Users can organize town halls. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `allow_webinars` (String) Users can organize webinars. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `description` (String) Description of the policy.
- `event_access_type` (String) Who can register for webinars. Valid values: `Everyone`, `EveryoneInCompanyExcludingGuests` (case-insensitive).
- `recording_for_townhall` (String) Town hall recording. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `recording_for_webinar` (String) Webinar recording. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `transcription_for_townhall` (String) Town hall transcription. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `transcription_for_webinar` (String) Webinar transcription. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `use_microsoft_ecdn` (Boolean) Use the Microsoft eCDN for town halls.

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix shown by `Get-Cs*Policy` is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_events_policy.example
  id = "Internal-Events"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_events_policy.example
  identity = { id = "Internal-Events" }
}
```

Or with the CLI:

```shell
terraform import msteams_events_policy.example "Internal-Events"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
