# msteams_update_management_policy (Resource)

Manages a Teams update management policy, which controls preview features and update notifications (`CsTeamsUpdateManagementPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# Pilot users get the public preview of the Teams client.
resource "msteams_update_management_policy" "pilot" {
  name                 = "Pilot-Preview"
  description          = "Early access to Teams features"
  allow_public_preview = "Enabled"
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `allow_managed_updates` (Boolean) Let administrators manage update notifications.
- `allow_preview` (Boolean) Show preview features to users.
- `allow_public_preview` (String) Public preview of the Teams client. Valid values: `Disabled`, `Enabled`, `Forced`, `FollowOfficePreview` (case-insensitive).
- `description` (String) Description of the policy.
- `update_day_of_week` (Number) Day of the week for update notifications, from `0` (Sunday) to `6`.
- `update_time` (String) Time of day for update notifications, as `HH:mm`.

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix shown by `Get-Cs*Policy` is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_update_management_policy.example
  id = "Pilot-Preview"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_update_management_policy.example
  identity = { id = "Pilot-Preview" }
}
```

Or with the CLI:

```shell
terraform import msteams_update_management_policy.example "Pilot-Preview"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
