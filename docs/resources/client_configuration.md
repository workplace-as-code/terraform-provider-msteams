# msteams_client_configuration (Resource)

Manages the tenant-wide Teams client configuration (`CsTeamsClientConfiguration`). This is a singleton: there is exactly one configuration per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Teams.

## Example Usage

```terraform
# Tenant-wide Teams client settings. Only the attributes listed here are
# managed; the others keep their current value.
resource "msteams_client_configuration" "this" {
  allow_drop_box     = false
  allow_box          = false
  allow_google_drive = false
  allow_share_file   = false
  allow_egnyte       = false

  allow_email_into_channel = true
  restricted_sender_list   = "contoso.com;fabrikam.com"
}
```

## Schema

### Optional

- `allow_box` (Boolean) Allow Box as a cloud storage provider in Teams.
- `allow_drop_box` (Boolean) Allow Dropbox as a cloud storage provider in Teams.
- `allow_egnyte` (Boolean) Allow Egnyte as a cloud storage provider in Teams.
- `allow_email_into_channel` (Boolean) Allow users to post to a channel by sending an email to the channel address.
- `allow_google_drive` (Boolean) Allow Google Drive as a cloud storage provider in Teams.
- `allow_guest_user` (Boolean) Allow guest users to access the Teams client. Requires guest access to be enabled in the tenant.
- `allow_organization_tab` (Boolean) Show the organization chart on contact cards.
- `allow_scoped_people_search_and_access` (Boolean) Use Exchange address book policies to scope people search in Teams.
- `allow_share_file` (Boolean) Allow Citrix ShareFile as a cloud storage provider in Teams.
- `allow_skype_business_interop` (Boolean) Show Teams conversations in Skype for Business for users not enabled for Teams.
- `content_pin` (String) Secondary authentication for resource accounts accessing meeting content (Skype for Business Online only). Valid values: `NotRequired`, `RequiredOutsideScheduleMeeting`, `AlwaysRequired` (case-insensitive).
- `restricted_sender_list` (String) Semicolon-separated list of SMTP domains allowed to send email to Teams channels. Empty means any domain.

### Read-Only

- `id` (String) Always `Global`.

## Import

The resource is a singleton. Import it with the ID `Global`:

```terraform
import {
  to = msteams_client_configuration.this
  id = "Global"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_client_configuration.this
  identity = { id = "Global" }
}
```

Or with the CLI:

```shell
terraform import msteams_client_configuration.this "Global"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
