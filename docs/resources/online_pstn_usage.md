# msteams_online_pstn_usage (Resource)

Manages a PSTN usage of the tenant (`Set-CsOnlinePstnUsage`), a name that links Direct Routing voice routes to the voice routing policies whose users can take them. Destroying the resource removes the usage from the tenant: Teams refuses while a voice route or policy still uses it.

## Example Usage

```terraform
# Usages link the voice routes to the voice routing policies.
resource "msteams_online_pstn_usage" "france" {
  name = "France"
}

resource "msteams_online_pstn_usage" "international" {
  name = "International"
}
```
