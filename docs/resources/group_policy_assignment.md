# msteams_group_policy_assignment (Resource)

Assigns a Teams policy to the members of a group (`New-CsGroupPolicyAssignment`). Members get the policy unless a policy of the same type is assigned to them directly, or through a group with a lower `rank`. Teams cannot change an assignment in place: changing any attribute replaces it.

## Example Usage

```terraform
resource "msteams_meeting_policy" "external" {
  name                = "External-Meetings"
  auto_admitted_users = "EveryoneInCompanyExcludingGuests"
}

# Members of the Sales group get the External-Meetings policy. Rank 1 wins
# over the other group assignments of meeting policies.
resource "msteams_group_policy_assignment" "sales_meetings" {
  group_id    = var.sales_group_id
  policy_type = "TeamsMeetingPolicy"
  policy_name = msteams_meeting_policy.external.name
  rank        = 1
}

variable "sales_group_id" {
  description = "Object ID of the Sales group in Entra ID"
  type        = string
}
```

## Schema

### Required

- `group_id` (String) Object ID of the Entra ID group: security group, distribution list or Microsoft 365 group.
- `policy_name` (String) Name of the policy to assign, for example `msteams_meeting_policy.example.name`.
- `policy_type` (String) Policy type, for example `TeamsMeetingPolicy`, `TeamsMessagingPolicy`, `TeamsCallingPolicy`, `TeamsAppSetupPolicy`, `TeamsChannelsPolicy`, `TeamsUpdateManagementPolicy`, `TeamsFeedbackPolicy` or `TeamsEventsPolicy`. A group can have one assignment per policy type.
- `rank` (Number) Priority of this assignment over the other group assignments of the same policy type. `1` wins over every other rank.

### Read-Only

- `id` (String) `<group_id>/<policy_type>`.

## Permissions

The provider's app registration needs the **Teams Administrator** Entra ID role, and no other permission. Only when that role is scoped to administrative units does it also need the Microsoft Graph `GroupMember.Read.All` application permission, with admin consent ([Microsoft documentation](https://learn.microsoft.com/microsoftteams/teams-powershell-application-authentication)). See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
