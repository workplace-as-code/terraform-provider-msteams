# msteams_messaging_policy (Resource)

Manages a Teams messaging policy, which controls the chat and channel messaging features available to the users it is assigned to (`CsTeamsMessagingPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# Restrictive messaging for students: no Giphy, memes or message deletion.
resource "msteams_messaging_policy" "students" {
  name        = "Students"
  description = "Messaging policy for student accounts"

  allow_user_delete_message  = false
  allow_owner_delete_message = true
  allow_giphy                = false
  allow_memes                = false
  allow_stickers             = true
  read_receipts_enabled_type = "Everyone"
}

# Frontline workers: chat allowed, audio messages in chats only.
resource "msteams_messaging_policy" "frontline" {
  name                       = "Frontline"
  audio_message_enabled_type = "ChatsOnly"
  allow_priority_messages    = true
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `allow_giphy` (Boolean) Allow users to post Giphy images.
- `allow_immersive_reader` (Boolean) Allow users to open messages in Immersive Reader.
- `allow_memes` (Boolean) Allow users to post memes.
- `allow_owner_delete_message` (Boolean) Allow team owners to delete any message in their team.
- `allow_priority_messages` (Boolean) Allow users to send priority (urgent) messages.
- `allow_remove_user` (Boolean) Allow users to remove people from group chats.
- `allow_smart_compose` (Boolean) Offer text predictions while composing messages.
- `allow_smart_reply` (Boolean) Offer suggested replies in chat.
- `allow_stickers` (Boolean) Allow users to post stickers.
- `allow_url_previews` (Boolean) Show automatic previews of URLs in messages.
- `allow_user_chat` (Boolean) Allow users to chat. `false` blocks private, group and meeting chat.
- `allow_user_delete_chat` (Boolean) Allow users to delete 1:1, group and meeting chats for themselves.
- `allow_user_delete_message` (Boolean) Allow users to delete their own messages.
- `allow_user_edit_message` (Boolean) Allow users to edit their own messages.
- `allow_user_translation` (Boolean) Allow users to translate messages inline.
- `allow_video_messages` (Boolean) Allow users to record and send video messages.
- `audio_message_enabled_type` (String) Audio messages. Valid values: `ChatsAndChannels`, `ChatsOnly`, `Disabled` (case-insensitive).
- `description` (String) Description of the policy.
- `giphy_rating_type` (String) Giphy content rating. Valid values: `Strict`, `Moderate`, `NoRestriction` (case-insensitive).
- `read_receipts_enabled_type` (String) Read receipts. Valid values: `UserPreference`, `Everyone`, `None` (case-insensitive).

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix shown by `Get-Cs*Policy` is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_messaging_policy.example
  id = "Students"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_messaging_policy.example
  identity = { id = "Students" }
}
```

Or with the CLI:

```shell
terraform import msteams_messaging_policy.example "Students"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
