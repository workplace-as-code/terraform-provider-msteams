# msteams_emergency_calling_policy (Resource)

Manages a Teams emergency calling policy, which notifies security staff when a user calls an emergency number (`CsTeamsEmergencyCallingPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# The Paris security desk is told of every emergency call.
resource "msteams_emergency_calling_policy" "paris" {
  name                          = "Paris"
  notification_mode             = "NotificationOnly"
  notification_group            = "security-paris@contoso.com"
  external_location_lookup_mode = "Enabled"
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `description` (String) Description of the policy.
- `enhanced_emergency_service_disclaimer` (String) Text shown to users who have not confirmed their emergency address.
- `external_location_lookup_mode` (String) Whether users working from home can set their emergency address. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `notification_dial_out_number` (String) Phone number called to join the emergency call, with `ConferenceMuted` or `ConferenceUnMuted`.
- `notification_group` (String) Email addresses of the users and groups to notify, separated by semicolons. Required with `NotificationOnly`.
- `notification_mode` (String) How the notified people take part in the emergency call. Valid values: `NotificationOnly`, `ConferenceMuted`, `ConferenceUnMuted` (case-insensitive).

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_emergency_calling_policy.paris
  id = "Paris"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_emergency_calling_policy.paris
  identity = { id = "Paris" }
}
```

Or with the CLI:

```shell
terraform import msteams_emergency_calling_policy.paris "Paris"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
