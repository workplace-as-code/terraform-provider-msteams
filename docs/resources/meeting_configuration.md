# msteams_meeting_configuration (Resource)

Manages the tenant-wide Teams meeting configuration (`CsTeamsMeetingConfiguration`). This is a singleton: there is exactly one configuration per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Teams.

## Example Usage

```terraform
# Tenant-wide meeting settings: block anonymous join and pin media ports so the
# network team can apply QoS rules.
resource "msteams_meeting_configuration" "this" {
  disable_anonymous_join = true

  enable_qos                      = true
  client_media_port_range_enabled = true
  client_audio_port               = 50000
  client_audio_port_range         = 20
  client_video_port               = 50020
  client_video_port_range         = 20
  client_app_sharing_port         = 50040
  client_app_sharing_port_range   = 20

  legal_url = "https://contoso.com/legal/meetings"
  help_url  = "https://support.contoso.com/teams"
}
```

## Schema

### Optional

- `client_app_sharing_port` (Number) First port used for client screen and app sharing (1024-65535). Teams default: 50040.
- `client_app_sharing_port_range` (Number) Number of ports available for client screen and app sharing. Teams default: 20.
- `client_audio_port` (Number) First port used for client audio (1024-65535). Teams default: 50000.
- `client_audio_port_range` (Number) Number of ports available for client audio. Teams default: 20.
- `client_media_port_range_enabled` (Boolean) Force clients to use the port ranges below for media. When `false`, any port from 1024 to 65535 is used.
- `client_video_port` (Number) First port used for client video (1024-65535). Teams default: 50020.
- `client_video_port_range` (Number) Number of ports available for client video. Teams default: 20.
- `custom_footer_text` (String) Footer text included in meeting invitations.
- `disable_anonymous_join` (Boolean) Block anonymous users from joining meetings.
- `disable_app_interaction_for_anonymous_users` (Boolean) Prevent anonymous users from interacting with apps in meetings.
- `enable_qos` (Boolean) Enable Quality of Service (QoS) marking for real-time media.
- `help_url` (String) URL of a help page included in meeting invitations.
- `legal_url` (String) URL of a legal or disclaimer page included in meeting invitations.
- `logo_url` (String) URL of a logo image included in meeting invitations. Must be publicly reachable.

### Read-Only

- `id` (String) Always `Global`.

## Import

The resource is a singleton. Import it with the ID `Global`:

```terraform
import {
  to = msteams_meeting_configuration.this
  id = "Global"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_meeting_configuration.this
  identity = { id = "Global" }
}
```

Or with the CLI:

```shell
terraform import msteams_meeting_configuration.this "Global"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
