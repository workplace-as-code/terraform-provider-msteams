# msteams_emergency_call_routing_policy (Resource)

Manages a Teams emergency call routing policy: the emergency numbers of Direct Routing users and the PSTN usages that carry their calls (`CsTeamsEmergencyCallRoutingPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
resource "msteams_online_pstn_usage" "emergency" {
  name = "Emergency France"
}

# 112, and the numbers users may dial for it, through the emergency routes.
resource "msteams_emergency_call_routing_policy" "france" {
  name                              = "France"
  allow_enhanced_emergency_services = true

  emergency_numbers = [
    {
      dial_string = "112"
      dial_mask   = "15;17;18"
      pstn_usage  = msteams_online_pstn_usage.emergency.name
    },
  ]
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `allow_enhanced_emergency_services` (Boolean) Whether dynamic emergency calling (location-based routing of emergency calls) is on.
- `description` (String) Description of the policy.
- `emergency_numbers` (Attributes List) Emergency numbers. (see [below for nested schema](#nestedatt--emergency_numbers))

### Read-Only

- `id` (String) The policy name (same as `name`).

<a id="nestedatt--emergency_numbers"></a>
### Nested Schema for `emergency_numbers`

Required:

- `dial_string` (String) Emergency number sent to the PSTN, for example `112`.

Optional:

- `dial_mask` (String) Other numbers users may dial for it, separated by semicolons, for example `911;999`.
- `pstn_usage` (String) PSTN usage whose voice routes carry the call.

## Import

Import using the policy name. The `Tag:` prefix is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_emergency_call_routing_policy.france
  id = "France"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_emergency_call_routing_policy.france
  identity = { id = "France" }
}
```

Or with the CLI:

```shell
terraform import msteams_emergency_call_routing_policy.france "France"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
