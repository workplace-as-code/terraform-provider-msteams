# msteams_channels_policy (Resource)

Manages a Teams channels policy, which controls team discovery and the creation of private and shared channels (`CsTeamsChannelsPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# No shared channels with other organizations.
resource "msteams_channels_policy" "internal" {
  name        = "Internal-Channels"
  description = "Private channels allowed, no external sharing"

  allow_private_channel_creation                       = true
  allow_shared_channel_creation                        = true
  allow_channel_sharing_to_external_user               = false
  allow_user_to_participate_in_external_shared_channel = false
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `allow_channel_sharing_to_external_user` (Boolean) Allow owners to share channels with people in other organizations.
- `allow_org_wide_team_creation` (Boolean) Allow global administrators to create org-wide teams.
- `allow_private_channel_creation` (Boolean) Allow team owners and members to create private channels.
- `allow_shared_channel_creation` (Boolean) Allow team owners to create shared channels.
- `allow_user_to_participate_in_external_shared_channel` (Boolean) Allow users to join channels shared by other organizations.
- `description` (String) Description of the policy.
- `enable_private_team_discovery` (Boolean) Show private teams in team discovery results.

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix shown by `Get-Cs*Policy` is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_channels_policy.example
  id = "Internal-Channels"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_channels_policy.example
  identity = { id = "Internal-Channels" }
}
```

Or with the CLI:

```shell
terraform import msteams_channels_policy.example "Internal-Channels"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
