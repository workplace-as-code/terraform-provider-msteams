# msteams_guest_calling_configuration (Resource)

Manages the calling features available to guest users (`CsTeamsGuestCallingConfiguration`). This is a singleton: there is exactly one configuration per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Teams.

## Example Usage

```terraform
# Guests cannot place 1:1 calls.
resource "msteams_guest_calling_configuration" "this" {
  allow_private_calling = false
}
```

## Import

The resource is a singleton. Import it with the ID `Global`:

```terraform
import {
  to = msteams_guest_calling_configuration.this
  id = "Global"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_guest_calling_configuration.this
  identity = { id = "Global" }
}
```

Or with the CLI:

```shell
terraform import msteams_guest_calling_configuration.this "Global"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
