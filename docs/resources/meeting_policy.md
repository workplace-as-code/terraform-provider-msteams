# msteams_meeting_policy (Resource)

Manages a Teams meeting policy, which controls the meeting features available to the organizers and participants it is assigned to (`CsTeamsMeetingPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# Meetings for external-facing staff: guests wait in the lobby, recordings
# expire after 60 days.
resource "msteams_meeting_policy" "external" {
  name        = "External-Meetings"
  description = "Meetings with customers and partners"

  auto_admitted_users                   = "EveryoneInCompanyExcludingGuests"
  allow_pstn_users_to_bypass_lobby      = false
  allow_anonymous_users_to_join_meeting = true
  allow_cloud_recording                 = true
  new_meeting_recording_expiration_days = 60
  allow_transcription                   = true
  screen_sharing_mode                   = "SingleApplication"
}

# The org-wide default policy is adopted, not created: destroying this
# resource only removes it from Terraform state.
resource "msteams_meeting_policy" "global" {
  name                    = "Global"
  allow_breakout_rooms    = true
  allow_meeting_reactions = true
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `allow_anonymous_users_to_dial_out` (Boolean) Allow anonymous users to dial out to a phone number from the meeting.
- `allow_anonymous_users_to_join_meeting` (Boolean) Allow anonymous users to join the meetings these users organize.
- `allow_anonymous_users_to_start_meeting` (Boolean) Allow anonymous users to start a meeting before the organizer joins.
- `allow_breakout_rooms` (Boolean) Allow breakout rooms.
- `allow_channel_meeting_scheduling` (Boolean) Allow users to schedule channel meetings.
- `allow_cloud_recording` (Boolean) Allow meetings to be recorded.
- `allow_engagement_report` (String) Attendance report, for example `Enabled`, `Disabled` or `ForceEnabled`.
- `allow_external_non_trusted_meeting_chat` (Boolean) Allow chat with external participants from organizations that are not trusted.
- `allow_external_participant_give_request_control` (Boolean) Allow external participants to give or request control of shared content.
- `allow_ip_audio` (Boolean) Allow audio in meetings and group calls.
- `allow_ip_video` (Boolean) Allow video in meetings and group calls.
- `allow_meet_now` (Boolean) Allow users to start instant meetings in channels.
- `allow_meeting_reactions` (Boolean) Allow live reactions.
- `allow_meeting_registration` (Boolean) Allow meetings that require registration.
- `allow_organizers_to_override_lobby_settings` (Boolean) Let organizers change the lobby settings of their meetings.
- `allow_outlook_add_in` (Boolean) Allow users to schedule Teams meetings from Outlook.
- `allow_participant_give_request_control` (Boolean) Allow participants to give or request control of shared content.
- `allow_power_point_sharing` (Boolean) Allow PowerPoint Live sharing.
- `allow_private_meet_now` (Boolean) Allow users to start instant private meetings.
- `allow_private_meeting_scheduling` (Boolean) Allow users to schedule private meetings.
- `allow_pstn_users_to_bypass_lobby` (Boolean) Let dial-in (PSTN) participants bypass the lobby.
- `allow_recording_storage_outside_region` (Boolean) Allow recordings to be stored outside the tenant's region.
- `allow_shared_notes` (Boolean) Allow shared meeting notes.
- `allow_transcription` (Boolean) Allow meeting transcription.
- `allow_whiteboard` (Boolean) Allow Whiteboard in meetings.
- `auto_admitted_users` (String) Who joins the meeting directly, without waiting in the lobby. Valid values: `EveryoneInCompany`, `EveryoneInSameAndFederatedCompany`, `EveryoneInCompanyExcludingGuests`, `OrganizerOnly`, `InvitedUsers`, `Everyone` (case-insensitive).
- `copilot` (String) Copilot in meetings, for example `Enabled`, `EnabledWithTranscript` or `Disabled`.
- `description` (String) Description of the policy.
- `designated_presenter_role_mode` (String) Default value of "Who can present", for example `EveryoneUserOverride`, `EveryoneInCompanyUserOverride` or `OrganizerOnlyUserOverride`.
- `explicit_recording_consent` (String) Require participants to consent before being recorded: `Enabled` or `Disabled`.
- `external_meeting_join` (String) Joining meetings of other organizations, for example `EnabledForAnyone`, `EnabledForTrustedOrgs` or `Disabled`.
- `ip_audio_mode` (String) Audio mode. Valid values: `EnabledOutgoingIncoming`, `Disabled` (case-insensitive).
- `ip_video_mode` (String) Video mode. Valid values: `EnabledOutgoingIncoming`, `Disabled` (case-insensitive).
- `live_captions_enabled_type` (String) Live captions. Valid values: `DisabledUserOverride`, `Disabled` (case-insensitive).
- `media_bit_rate_kb` (Number) Media bit rate in Kbps for audio, video and screen sharing.
- `meeting_chat_enabled_type` (String) Meeting chat, for example `Enabled`, `Disabled` or `EnabledExceptAnonymous`.
- `new_meeting_recording_expiration_days` (Number) Number of days before new meeting recordings expire. `-1` means they never expire.
- `screen_sharing_mode` (String) Screen sharing. Valid values: `EntireScreen`, `SingleApplication`, `Disabled` (case-insensitive).
- `who_can_register` (String) Who can register for meetings that require registration. Valid values: `Everyone`, `EveryoneInCompany` (case-insensitive).

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix shown by `Get-Cs*Policy` is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_meeting_policy.example
  id = "External-Meetings"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_meeting_policy.example
  identity = { id = "External-Meetings" }
}
```

Or with the CLI:

```shell
terraform import msteams_meeting_policy.example "External-Meetings"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
