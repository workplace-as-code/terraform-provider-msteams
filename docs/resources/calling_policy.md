# msteams_calling_policy (Resource)

Manages a Teams calling policy, which controls the calling and call forwarding features available to the users it is assigned to (`CsTeamsCallingPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# No forwarding to external numbers, voicemail always on.
resource "msteams_calling_policy" "restricted" {
  name        = "Restricted-Calling"
  description = "Internal calling only"

  allow_private_calling          = true
  allow_call_forwarding_to_user  = true
  allow_call_forwarding_to_phone = false
  allow_voicemail                = "AlwaysEnabled"
  busy_on_busy_enabled_type      = "Enabled"
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `allow_call_forwarding_to_phone` (Boolean) Allow forwarding and simultaneous ringing to external phone numbers.
- `allow_call_forwarding_to_user` (Boolean) Allow forwarding and simultaneous ringing to other users.
- `allow_call_groups` (Boolean) Allow call groups.
- `allow_call_redirect` (String) Redirecting incoming calls. Valid values: `Enabled`, `Disabled`, `UserOverride` (case-insensitive).
- `allow_cloud_recording_for_calls` (Boolean) Allow 1:1 calls to be recorded.
- `allow_delegation` (Boolean) Allow users to make and receive calls on behalf of others.
- `allow_private_calling` (Boolean) Allow 1:1 calls.
- `allow_sip_devices_calling` (Boolean) Allow SIP devices to make and receive calls.
- `allow_transcription_for_calling` (Boolean) Allow 1:1 call transcription.
- `allow_voicemail` (String) Voicemail for unanswered calls. Valid values: `AlwaysEnabled`, `AlwaysDisabled`, `UserOverride` (case-insensitive).
- `allow_web_pstn_calling` (Boolean) Allow PSTN calls from the Teams web client.
- `auto_answer_enabled_type` (String) Automatic answer of incoming meeting invites. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `busy_on_busy_enabled_type` (String) Behavior for incoming calls when the user is already in a call. Valid values: `Enabled`, `Disabled`, `Unanswered`, `UserOverride` (case-insensitive).
- `call_recording_expiration_days` (Number) Number of days before 1:1 call recordings expire.
- `description` (String) Description of the policy.
- `live_captions_enabled_type_for_calling` (String) Live captions in 1:1 calls. Valid values: `DisabledUserOverride`, `Disabled` (case-insensitive).
- `music_on_hold_enabled_type` (String) Music on hold. Valid values: `Enabled`, `Disabled`, `UserOverride` (case-insensitive).
- `prevent_toll_bypass` (Boolean) Send calls through the PSTN instead of the network to avoid toll bypass.
- `spam_filtering_enabled_type` (String) Spam filtering of incoming PSTN calls. Valid values: `Enabled`, `Disabled` (case-insensitive).

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix shown by `Get-Cs*Policy` is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_calling_policy.example
  id = "Restricted-Calling"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_calling_policy.example
  identity = { id = "Restricted-Calling" }
}
```

Or with the CLI:

```shell
terraform import msteams_calling_policy.example "Restricted-Calling"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
