# msteams_guest_meeting_configuration (Resource)

Manages the meeting features available to guest users (`CsTeamsGuestMeetingConfiguration`). This is a singleton: there is exactly one configuration per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Teams.

## Example Usage

```terraform
# Guests can use video but only share a single application.
resource "msteams_guest_meeting_configuration" "this" {
  allow_ip_video      = true
  screen_sharing_mode = "SingleApplication"
  allow_meet_now      = false
}
```

## Schema

### Optional

- `allow_external_participant_give_request_control` (Boolean) Allow external guests to give or request control of shared content.
- `allow_ip_video` (Boolean) Allow guests to use video.
- `allow_meet_now` (Boolean) Allow guests to start instant meetings.
- `allow_multiple_screenshare` (Boolean) Allow guests to share their screen while someone else shares.
- `allow_participant_give_request_control` (Boolean) Allow guests to give or request control of shared content.
- `allow_transcription` (Boolean) Allow guests to use transcription.
- `live_captions_enabled_type` (String) Live captions for guests. Valid values: `DisabledUserOverride`, `Disabled` (case-insensitive).
- `screen_sharing_mode` (String) Screen sharing for guests. Valid values: `EntireScreen`, `SingleApplication`, `Disabled` (case-insensitive).

### Read-Only

- `id` (String) Always `Global`.
