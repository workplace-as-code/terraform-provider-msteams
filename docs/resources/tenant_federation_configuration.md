# msteams_tenant_federation_configuration (Resource)

Manages Teams external access: communication with users of other Microsoft 365 organizations and with unmanaged (personal) Teams accounts (`CsTenantFederationConfiguration`). This is a singleton: there is exactly one configuration per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Teams.

## Example Usage

```terraform
# External access only with two partner organizations, and no unmanaged
# (personal) Teams accounts.
resource "msteams_tenant_federation_configuration" "this" {
  allow_federated_users = true
  allowed_domains       = ["fabrikam.com", "contoso.com"]

  allow_teams_consumer         = false
  allow_teams_consumer_inbound = false
}
```

## Schema

### Optional

- `allow_federated_users` (Boolean) Allow users to communicate with users of other organizations.
- `allow_teams_consumer` (Boolean) Allow users to communicate with unmanaged (personal) Teams accounts.
- `allow_teams_consumer_inbound` (Boolean) Allow unmanaged Teams accounts to start conversations with users.
- `allowed_domains` (List of String) Domains users can communicate with. An empty list allows every domain except the blocked ones.
- `block_all_subdomains` (Boolean) Also block the subdomains of the blocked domains.
- `blocked_domains` (List of String) Domains users cannot communicate with. Only applies when `allowed_domains` is empty.
- `external_access_with_trial_tenants` (String) Communication with trial-only tenants. Valid values: `Allowed`, `Blocked` (case-insensitive).
- `restrict_teams_consumer_to_external_user_profiles` (Boolean) Limit communication with unmanaged accounts to the ones listed in external user profiles.
- `treat_discovered_partners_as_unverified` (Boolean) Treat organizations discovered through federation as unverified.

### Read-Only

- `id` (String) Always `Global`.

## Import

The resource is a singleton. Import it with the ID `Global`:

```terraform
import {
  to = msteams_tenant_federation_configuration.this
  id = "Global"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_tenant_federation_configuration.this
  identity = { id = "Global" }
}
```

Or with the CLI:

```shell
terraform import msteams_tenant_federation_configuration.this "Global"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
