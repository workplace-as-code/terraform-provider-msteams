# msteams_feedback_policy (Resource)

Manages a Teams feedback policy, which controls whether users can send feedback and receive surveys (`CsTeamsFeedbackPolicy`). Attributes left out of the configuration take the Teams default when the policy is created and are not managed afterwards.

## Example Usage

```terraform
# No surveys and no screenshots in feedback.
resource "msteams_feedback_policy" "quiet" {
  name                        = "No-Surveys"
  user_initiated_mode         = "Enabled"
  receive_surveys_mode        = "Disabled"
  allow_screenshot_collection = false
  allow_log_collection        = false
}
```

## Schema

### Required

- `name` (String) The policy name. Changing it creates a new policy. `Global` manages the org-wide default policy: it is adopted instead of created, and destroying the resource only removes it from Terraform state.

### Optional

- `allow_email_collection` (Boolean) Users can share their email address with their feedback.
- `allow_log_collection` (Boolean) Users can attach logs to their feedback.
- `allow_screenshot_collection` (Boolean) Users can attach a screenshot to their feedback.
- `receive_surveys_mode` (String) Users receive Microsoft surveys. Valid values: `Enabled`, `Disabled`, `EnabledUserOverride` (case-insensitive).
- `user_initiated_mode` (String) Users can give feedback from Help > Give feedback. Valid values: `Enabled`, `Disabled` (case-insensitive).

### Read-Only

- `id` (String) The policy name (same as `name`).

## Import

Import using the policy name. The `Tag:` prefix shown by `Get-Cs*Policy` is accepted, and `Global` imports the org-wide default policy:

```terraform
import {
  to = msteams_feedback_policy.example
  id = "No-Surveys"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msteams_feedback_policy.example
  identity = { id = "No-Surveys" }
}
```

Or with the CLI:

```shell
terraform import msteams_feedback_policy.example "No-Surveys"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/import_existing).
