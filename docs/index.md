# Microsoft Teams Provider

The Microsoft Teams provider manages Teams policies, policy assignments, external and guest access, and tenant-wide settings as code. It drives the MicrosoftTeams PowerShell module through scripts embedded in the provider binary. The machine running Terraform needs:

- PowerShell 7+ (`pwsh`) with the MicrosoftTeams module: `Install-Module MicrosoftTeams -Scope CurrentUser`
- An Entra ID app registration with a certificate, the `Organization.Read.All` Graph application permission and the Teams Administrator role. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).

When something fails, start with the [Troubleshooting guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/troubleshooting).

## Example Usage

```terraform
terraform {
  required_providers {
    msteams = {
      source  = "workplace-as-code/msteams"
      version = "~> 0.1"
    }
  }
}

provider "msteams" {
  tenant_id            = "contoso.onmicrosoft.com"
  client_id            = var.client_id
  certificate_path     = var.certificate_path
  certificate_password = var.certificate_password
}

resource "msteams_messaging_policy" "students" {
  name        = "Students"
  allow_giphy = false
  allow_memes = false
}
```

Every argument can also come from a `TEAMS_*` environment variable, for example `TEAMS_TENANT_ID`. A value set in the provider block takes precedence over the environment.

## Schema

### Optional

- `certificate_password` (String, Sensitive) Password for the `.pfx` certificate file. Can also be set via `TEAMS_CERTIFICATE_PASSWORD` environment variable.
- `certificate_path` (String) Path to the `.pfx` certificate file for app-only (CBA) authentication. Use this or `certificate_thumbprint`. Can also be set via `TEAMS_CERTIFICATE_PATH` environment variable.
- `certificate_thumbprint` (String) Thumbprint of a certificate already loaded in the Windows certificate store. Use this or `certificate_path`. Can also be set via `TEAMS_CERTIFICATE_THUMBPRINT` environment variable.
- `client_id` (String) Entra ID app registration client ID. Required, either here or via the `TEAMS_CLIENT_ID` environment variable.
- `environment` (String) M365 cloud environment. Valid values: `global` (default), `gcc`, `gcchigh`, `dod`. Can also be set via `TEAMS_ENVIRONMENT` environment variable.
- `tenant_id` (String) Entra ID tenant ID or `.onmicrosoft.com` domain. Required, either here or via the `TEAMS_TENANT_ID` environment variable.

## Performance tuning

The provider keeps a few PowerShell processes open during a run and reuses their Teams connection. These environment variables tune that behavior:

| Variable | Default | Effect |
|---|---|---|
| `TEAMS_MAX_CONCURRENCY` | `4` | Maximum number of PowerShell processes running at once |
| `TEAMS_SCRIPT_TIMEOUT` | `10m` | Maximum duration of one bridge call |
| `TEAMS_BRIDGE_MODE` | `persistent` | `oneshot` starts a new PowerShell process for every call |
| `TEAMS_WORKER_MAX_REQUESTS` | `200` | Requests served by a PowerShell process before it is replaced |
| `TEAMS_BRIDGE_DIR` | unset | Run the bridge scripts from this folder instead of the embedded copy (script development only) |
