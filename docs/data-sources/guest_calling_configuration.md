# msteams_guest_calling_configuration (Data Source)

Reads the tenant's configuration (`Global`), with the attributes of the [`msteams_guest_calling_configuration`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/guest_calling_configuration) resource, without managing it.

## Example Usage

```terraform
data "msteams_guest_calling_configuration" "this" {}

output "allow_private_calling" {
  description = "Whether guests can make private calls."
  value       = data.msteams_guest_calling_configuration.this.allow_private_calling
}
```

## Schema

### Read-Only

- `allow_private_calling` (Boolean) Allow guests to make 1:1 calls.
- `id` (String) Always `Global`.

## Permissions

The provider's app registration needs the **Teams Reader** Entra ID role, or Teams Administrator. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
