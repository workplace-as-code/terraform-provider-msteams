# msteams_meeting_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_meeting_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/meeting_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
# The org-wide default policy, which applies to every user without another one.
data "msteams_meeting_policy" "global" {
  name = "Global"
}

output "allow_meet_now" {
  description = "Whether users can start instant meetings, by default."
  value       = data.msteams_meeting_policy.global.allow_meet_now
}
```
