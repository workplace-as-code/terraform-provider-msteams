# msteams_emergency_calling_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_emergency_calling_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/emergency_calling_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
data "msteams_emergency_calling_policy" "global" {
  name = "Global"
}

output "global_notification_mode" {
  description = "Notification mode of the org-wide policy."
  value       = data.msteams_emergency_calling_policy.global.notification_mode
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `description` (String) Description of the policy.
- `enhanced_emergency_service_disclaimer` (String) Text shown to users who have not confirmed their emergency address.
- `external_location_lookup_mode` (String) Whether users working from home can set their emergency address. Valid values: `Enabled`, `Disabled` (case-insensitive).
- `id` (String) The policy name (same as `name`).
- `notification_dial_out_number` (String) Phone number called to join the emergency call, with `ConferenceMuted` or `ConferenceUnMuted`.
- `notification_group` (String) Email addresses of the users and groups to notify, separated by semicolons. Required with `NotificationOnly`.
- `notification_mode` (String) How the notified people take part in the emergency call. Valid values: `NotificationOnly`, `ConferenceMuted`, `ConferenceUnMuted` (case-insensitive).

## Permissions

The provider's app registration needs the **Teams Administrator** Entra ID role; the read-only Teams Reader role may not cover the voice cmdlets. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
