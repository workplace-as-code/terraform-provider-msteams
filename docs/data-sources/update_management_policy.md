# msteams_update_management_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_update_management_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/update_management_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
# The org-wide default policy, which applies to every user without another one.
data "msteams_update_management_policy" "global" {
  name = "Global"
}

output "allow_public_preview" {
  description = "Whether users can turn on the public preview, by default."
  value       = data.msteams_update_management_policy.global.allow_public_preview
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `allow_managed_updates` (Boolean) Let administrators manage update notifications.
- `allow_preview` (Boolean) Show preview features to users.
- `allow_public_preview` (String) Public preview of the Teams client. Valid values: `Disabled`, `Enabled`, `Forced`, `FollowOfficePreview` (case-insensitive).
- `description` (String) Description of the policy.
- `id` (String) The policy name (same as `name`).
- `update_day_of_week` (Number) Day of the week for update notifications, from `0` (Sunday) to `6`.
- `update_time` (String) Time of day for update notifications, as `HH:mm`.

## Permissions

The provider's app registration needs the **Teams Reader** Entra ID role, or Teams Administrator. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
