# msteams_app_setup_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_app_setup_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/app_setup_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
# The org-wide default policy, which applies to every user without another one.
data "msteams_app_setup_policy" "global" {
  name = "Global"
}

output "allow_side_loading" {
  description = "Whether users can upload custom apps, by default."
  value       = data.msteams_app_setup_policy.global.allow_side_loading
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `allow_side_loading` (Boolean) Allow users to upload custom apps.
- `allow_user_pinning` (Boolean) Allow users to pin apps to the app bar.
- `description` (String) Description of the policy.
- `id` (String) The policy name (same as `name`).

## Permissions

The provider's app registration needs the **Teams Reader** Entra ID role, or Teams Administrator. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
