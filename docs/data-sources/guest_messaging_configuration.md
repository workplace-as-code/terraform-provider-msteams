# msteams_guest_messaging_configuration (Data Source)

Reads the tenant's configuration (`Global`), with the attributes of the [`msteams_guest_messaging_configuration`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/guest_messaging_configuration) resource, without managing it.

## Example Usage

```terraform
data "msteams_guest_messaging_configuration" "this" {}

output "allow_giphy" {
  description = "Whether guests can use Giphy in chats."
  value       = data.msteams_guest_messaging_configuration.this.allow_giphy
}
```

## Schema

### Read-Only

- `allow_giphy` (Boolean) Allow guests to post Giphy images.
- `allow_immersive_reader` (Boolean) Allow guests to open messages in Immersive Reader.
- `allow_memes` (Boolean) Allow guests to post memes.
- `allow_stickers` (Boolean) Allow guests to post stickers.
- `allow_user_chat` (Boolean) Allow guests to chat.
- `allow_user_delete_chat` (Boolean) Allow guests to delete chats for themselves.
- `allow_user_delete_message` (Boolean) Allow guests to delete their messages.
- `allow_user_edit_message` (Boolean) Allow guests to edit their messages.
- `giphy_rating_type` (String) Giphy content rating for guests. Valid values: `Strict`, `Moderate`, `NoRestriction` (case-insensitive).
- `id` (String) Always `Global`.

## Permissions

The provider's app registration needs the **Teams Reader** Entra ID role, or Teams Administrator. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
