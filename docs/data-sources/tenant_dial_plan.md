# msteams_tenant_dial_plan (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_tenant_dial_plan`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/tenant_dial_plan) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
data "msteams_tenant_dial_plan" "global" {
  name = "Global"
}

output "global_normalization_rules" {
  description = "Normalization rules of the org-wide dial plan."
  value       = data.msteams_tenant_dial_plan.global.normalization_rules
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `description` (String) Description of the dial plan.
- `id` (String) The policy name (same as `name`).
- `normalization_rules` (Attributes List) Normalization rules, in the order Teams tries them: the first rule whose pattern matches the dialed number translates it. (see [below for nested schema](#nestedatt--normalization_rules))
- `simple_name` (String) Name of the dial plan shown in the clients. Defaults to the name.

<a id="nestedatt--normalization_rules"></a>
### Nested Schema for `normalization_rules`

Read-Only:

- `description` (String) Description of the rule.
- `is_internal_extension` (Boolean) Whether the rule translates an internal extension.
- `name` (String) Name of the rule, unique in the dial plan.
- `pattern` (String) Regular expression the dialed number must match, for example `^(\d{4})$`.
- `translation` (String) Number to call, with `$1`, `$2`... for the groups of the pattern, for example `+3314567$1`.

## Permissions

The provider's app registration needs the **Teams Reader** Entra ID role, or Teams Administrator. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
