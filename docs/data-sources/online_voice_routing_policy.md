# msteams_online_voice_routing_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_online_voice_routing_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/online_voice_routing_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
data "msteams_online_voice_routing_policy" "global" {
  name = "Global"
}

output "global_online_pstn_usages" {
  description = "PSTN usages of the org-wide policy."
  value       = data.msteams_online_voice_routing_policy.global.online_pstn_usages
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `description` (String) Description of the policy.
- `id` (String) The policy name (same as `name`).
- `online_pstn_usages` (List of String) PSTN usages, in the order Teams tries their voice routes.

## Permissions

The provider's app registration needs the **Teams Administrator** Entra ID role; the read-only Teams Reader role may not cover the voice cmdlets. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
