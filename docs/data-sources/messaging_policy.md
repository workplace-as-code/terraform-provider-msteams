# msteams_messaging_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_messaging_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/messaging_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
# The org-wide default policy, which applies to every user without another one.
data "msteams_messaging_policy" "global" {
  name = "Global"
}

output "allow_user_delete_message" {
  description = "Whether users can delete the messages they sent, by default."
  value       = data.msteams_messaging_policy.global.allow_user_delete_message
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `allow_giphy` (Boolean) Allow users to post Giphy images.
- `allow_immersive_reader` (Boolean) Allow users to open messages in Immersive Reader.
- `allow_memes` (Boolean) Allow users to post memes.
- `allow_owner_delete_message` (Boolean) Allow team owners to delete any message in their team.
- `allow_priority_messages` (Boolean) Allow users to send priority (urgent) messages.
- `allow_remove_user` (Boolean) Allow users to remove people from group chats.
- `allow_smart_compose` (Boolean) Offer text predictions while composing messages.
- `allow_smart_reply` (Boolean) Offer suggested replies in chat.
- `allow_stickers` (Boolean) Allow users to post stickers.
- `allow_url_previews` (Boolean) Show automatic previews of URLs in messages.
- `allow_user_chat` (Boolean) Allow users to chat. `false` blocks private, group and meeting chat.
- `allow_user_delete_chat` (Boolean) Allow users to delete 1:1, group and meeting chats for themselves.
- `allow_user_delete_message` (Boolean) Allow users to delete their own messages.
- `allow_user_edit_message` (Boolean) Allow users to edit their own messages.
- `allow_user_translation` (Boolean) Allow users to translate messages inline.
- `allow_video_messages` (Boolean) Allow users to record and send video messages.
- `audio_message_enabled_type` (String) Audio messages. Valid values: `ChatsAndChannels`, `ChatsOnly`, `Disabled` (case-insensitive).
- `description` (String) Description of the policy.
- `giphy_rating_type` (String) Giphy content rating. Valid values: `Strict`, `Moderate`, `NoRestriction` (case-insensitive).
- `id` (String) The policy name (same as `name`).
- `read_receipts_enabled_type` (String) Read receipts. Valid values: `UserPreference`, `Everyone`, `None` (case-insensitive).
