# msteams_feedback_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_feedback_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/feedback_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
# The org-wide default policy, which applies to every user without another one.
data "msteams_feedback_policy" "global" {
  name = "Global"
}

output "user_initiated_mode" {
  description = "Whether users can send feedback to Microsoft, by default."
  value       = data.msteams_feedback_policy.global.user_initiated_mode
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `allow_email_collection` (Boolean) Users can share their email address with their feedback.
- `allow_log_collection` (Boolean) Users can attach logs to their feedback.
- `allow_screenshot_collection` (Boolean) Users can attach a screenshot to their feedback.
- `id` (String) The policy name (same as `name`).
- `receive_surveys_mode` (String) Users receive Microsoft surveys. Valid values: `Enabled`, `Disabled`, `EnabledUserOverride` (case-insensitive).
- `user_initiated_mode` (String) Users can give feedback from Help > Give feedback. Valid values: `Enabled`, `Disabled` (case-insensitive).

## Permissions

The provider's app registration needs the **Teams Reader** Entra ID role, or Teams Administrator. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
