# msteams_channels_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_channels_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/channels_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
# The org-wide default policy, which applies to every user without another one.
data "msteams_channels_policy" "global" {
  name = "Global"
}

output "allow_private_channel_creation" {
  description = "Whether users can create private channels, by default."
  value       = data.msteams_channels_policy.global.allow_private_channel_creation
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `allow_channel_sharing_to_external_user` (Boolean) Allow owners to share channels with people in other organizations.
- `allow_org_wide_team_creation` (Boolean) Allow global administrators to create org-wide teams.
- `allow_private_channel_creation` (Boolean) Allow team owners and members to create private channels.
- `allow_shared_channel_creation` (Boolean) Allow team owners to create shared channels.
- `allow_user_to_participate_in_external_shared_channel` (Boolean) Allow users to join channels shared by other organizations.
- `description` (String) Description of the policy.
- `enable_private_team_discovery` (Boolean) Show private teams in team discovery results.
- `id` (String) The policy name (same as `name`).
