# msteams_emergency_call_routing_policy (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_emergency_call_routing_policy`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/emergency_call_routing_policy) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
data "msteams_emergency_call_routing_policy" "global" {
  name = "Global"
}

output "global_emergency_numbers" {
  description = "Emergency numbers of the org-wide policy."
  value       = data.msteams_emergency_call_routing_policy.global.emergency_numbers
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `allow_enhanced_emergency_services` (Boolean) Whether dynamic emergency calling (location-based routing of emergency calls) is on.
- `description` (String) Description of the policy.
- `emergency_numbers` (Attributes List) Emergency numbers. (see [below for nested schema](#nestedatt--emergency_numbers))
- `id` (String) The policy name (same as `name`).

<a id="nestedatt--emergency_numbers"></a>
### Nested Schema for `emergency_numbers`

Read-Only:

- `dial_mask` (String) Other numbers users may dial for it, separated by semicolons, for example `911;999`.
- `dial_string` (String) Emergency number sent to the PSTN, for example `112`.
- `pstn_usage` (String) PSTN usage whose voice routes carry the call.

## Permissions

The provider's app registration needs the **Teams Administrator** Entra ID role; the read-only Teams Reader role may not cover the voice cmdlets. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
