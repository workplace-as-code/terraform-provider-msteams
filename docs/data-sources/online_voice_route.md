# msteams_online_voice_route (Data Source)

Reads an existing policy by `name`, with the attributes of the [`msteams_online_voice_route`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/online_voice_route) resource. Use it to reference a policy that this configuration does not manage, such as `Global`.

## Example Usage

```terraform
data "msteams_online_voice_route" "local" {
  name = "LocalRoute"
}

output "local_number_pattern" {
  description = "Numbers matched by the default route."
  value       = data.msteams_online_voice_route.local.number_pattern
}
```

## Schema

### Required

- `name` (String) Name of the policy to read. `Global` reads the org-wide default policy.

### Read-Only

- `description` (String) Description of the route.
- `id` (String) The policy name (same as `name`).
- `number_pattern` (String) Regular expression of the called numbers, for example `^\+33\d{9}$`.
- `online_pstn_gateways` (List of String) FQDNs of the session border controllers (SBC) of the route, as registered with `New-CsOnlinePSTNGateway`.
- `online_pstn_usages` (List of String) PSTN usages the route belongs to.
- `priority` (Number) Order of the routes of a PSTN usage that match a number: 0 first.

## Permissions

The provider's app registration needs the **Teams Administrator** Entra ID role; the read-only Teams Reader role may not cover the voice cmdlets. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
