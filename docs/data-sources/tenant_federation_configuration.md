# msteams_tenant_federation_configuration (Data Source)

Reads the tenant's configuration (`Global`), with the attributes of the [`msteams_tenant_federation_configuration`](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/resources/tenant_federation_configuration) resource, without managing it.

## Example Usage

```terraform
data "msteams_tenant_federation_configuration" "this" {}

output "allowed_domains" {
  description = "Domains whose users can chat with the tenant."
  value       = data.msteams_tenant_federation_configuration.this.allowed_domains
}
```

## Schema

### Read-Only

- `allow_federated_users` (Boolean) Allow users to communicate with users of other organizations.
- `allow_teams_consumer` (Boolean) Allow users to communicate with unmanaged (personal) Teams accounts.
- `allow_teams_consumer_inbound` (Boolean) Allow unmanaged Teams accounts to start conversations with users.
- `allowed_domains` (List of String) Domains users can communicate with. An empty list allows every domain except the blocked ones.
- `block_all_subdomains` (Boolean) Also block the subdomains of the blocked domains.
- `blocked_domains` (List of String) Domains users cannot communicate with. Only applies when `allowed_domains` is empty.
- `external_access_with_trial_tenants` (String) Communication with trial-only tenants. Valid values: `Allowed`, `Blocked` (case-insensitive).
- `id` (String) Always `Global`.
- `restrict_teams_consumer_to_external_user_profiles` (Boolean) Limit communication with unmanaged accounts to the ones listed in external user profiles.
- `treat_discovered_partners_as_unverified` (Boolean) Treat organizations discovered through federation as unverified.

## Permissions

The provider's app registration needs the **Teams Reader** Entra ID role, or Teams Administrator. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msteams/latest/docs/guides/authentication).
